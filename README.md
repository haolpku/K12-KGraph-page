# K12-KGraph Project Page

Source for the [K12-KGraph](https://github.com/haolpku/K12-KGraph) project page,
a static site hosted on GitHub Pages.

- **Dataset (HF)**: https://huggingface.co/datasets/lhpku20010120/K12-KGraph
- **Released checkpoints**:
  - https://huggingface.co/lhpku20010120/llama3.1-8b-k12kgraph
  - https://huggingface.co/lhpku20010120/qwen3.5-2b-k12kgraph
  - https://huggingface.co/lhpku20010120/qwen3-4b-k12kgraph
- **Code**: https://github.com/haolpku/K12-KGraph

The site is plain HTML / CSS with no build step — just open `index.html`.

## Deploy

This repo is published via **GitHub Pages** from the `main` branch root.
After pushing, enable Pages in *Settings &rarr; Pages &rarr; Source: `main` / `/ (root)`*.
